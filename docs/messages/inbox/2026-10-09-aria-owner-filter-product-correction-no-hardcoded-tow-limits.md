## Explicit product requirement

Deal Sniffer is a general-purpose, user-configurable opportunity discovery / valuation / resale workflow. **Do NOT hard-code the owner's current no-gooseneck / no-heavy-tow circumstance as a platform-wide classifier rejection, global rule, or permanent feature limit.** It is a CURRENT USER PREFERENCE in one editable search profile. Other users and Michael tomorrow may want goosenecks or heavy trailers. The architecture must handle all supported equipment categories and multiple user profiles/presets, not special-case Michael.

Search UX:
- A single visible **Find Deals Now** action and a compact filter panel with simple defaults, Advanced expandable.
- Category multi-select: trailers, machinery/equipment, mowers, generators, ATVs, tools, vehicles, commercial equipment, all deals. Other types remain searchable; don't restrict to trailers.
- Trailer subtype selectable/multiselect: gooseneck, bumper-pull, utility, equipment, boat, landscape, enclosed, car hauler, camper donor/frame, etc. Type is data, not a distinct silo. Optional length, width, axle count, payload/GVWR and tongue/gooseneck coupling if seller lists it; UNKNOWN if not.
- Editable condition (working/running, minor repair, damaged, non-running, parts), price/cash available, distance, location, paperwork/title/VIN, auction vs fixed price, closing time, predicted net profit, expected days to cash, and transportation constraints.
- Transportation filter **can tow personally / transport required / delivered / all** with editable tow vehicle and safe verified towing limits as user fields; if unknown, don't assert towable. Heavy deals can be WATCH/MAYBE conditional on hired transport, and costs/time factored into economics. Do not suggest unsafe towing.
- Saved filter presets (e.g. "Trailers I can tow this week", "All profitable trailers", "All bargain equipment", "Auctions closing soon") with freely editable toggles and reset to All.
- Ranking according to the selected user profile and live provenance; if a category excluded by selected filter, explain filtered out rather than blacklist or delete. A future resale marketplace product must be usable by other buyers without changing source code.
- Still preserve owner-first priority of affordable trailers and towables as default saved preset only; don't change global source discovery or valuation to skip goosenecks/heavy machinery.

This is a **correction** to previous instruction to 'stop treating heavy trailers as easy pickups'. Correct version: keep them discoverable; show explicit transport feasibility and added delivery costs; allow one temporary saved preference to de-emphasize impossible pickups.
