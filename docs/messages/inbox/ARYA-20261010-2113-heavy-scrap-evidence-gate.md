# Existing component/exit guideline: heavy scrap feasibility gate

Michael's explicit decision rule: "we can't make a bid because we don't know what it's gonna cost to move an eleven-ton machine".

Docs-only addition to existing DEAL_SNIFFER_START_HERE section13b. No new implementation task or worker:
- Before recommending a bid for a heavy asset on scrap/component recovery, verify whether a yard accepts the actual material/item and obtain supported net pickup-offer evidence, OR establish realistic transport, loading/unloading and any necessary cutting/disassembly costs.
- Establish actual weight/dimensions, loading capability/equipment and site access, pickup deadline and removal obligations, title/paperwork and all applicable fees. Seller's loading help or yard pickup is not assumed.
- Derive any supported bid ceiling only after these costs and feasibility constraints are known; unknown material transport/removal costs block a bid recommendation. Show the exact missing evidence instead of invented profit.
- Distinguish gross scrap value from net realized proceeds after pickup/transport/cutting/fees/disposal. Do not double count components and whole-asset scrap alternatives.
- "Why didn't the seller scrap it?" is a due-diligence question, not evidence of a bad deal, guaranteed profit or hidden defect. State hypotheses as hypotheses until verified.

No private owner financial examples. No yard calls/contact, bids, purchases, inventory refresh or live changes. Preserve current A59/A60/A61/A62 queue and latest owner instructions. Return canonical doc adoption; no automated implementation claim.
