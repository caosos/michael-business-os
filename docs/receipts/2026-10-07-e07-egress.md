- **`egress.check_catalog()`** runs inside the policy loader, so any problem makes the policy unavailable and the gateway denies everything. It rejects:
  - wildcards, non-FQDNs, IP literals
  - local, internal and reserved names (`.local`, `.internal`, `.test`, …)
  - uppercase names and trailing dots
  - unknown owners
  - an id prefix that does not match the kind
  - non-read-only source adapters
  - duplicate ids
- **`egress.effective_allow()`** returns the enabled entries plus the legacy `allow`, minus L1-frozen agents. It returns nothing when the policy or PANIC is unreadable or L3 is engaged.
- **`render_egress`** (the E-03 hook and `mbos-gov render egress`) now emits the effective allow-list and the catalog.
