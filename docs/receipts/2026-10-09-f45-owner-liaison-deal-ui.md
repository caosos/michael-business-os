# F-45 receipt: owner-liaison gaps closed in the existing Operator UI (DRY-RUN)

- **Task:** F-45 (P1), after F-39. Lane 06, branch `research/agent-06-communications`. No new dashboard: changes are on `/resale`, `/notes` and the page chrome.
- **What changed (FACT, from the code):** new `operator_ui/deal_ui.py`; `resale_view.py` (proof split out, UI-only keys kept from the engine, DEMO fixtures extended); `server.py` (active-nav, page heading, CSP `img-src`, filters/presets/tow routes, `/notes/add`).
  1. **Links:** `classify_url`: fixture hosts (`.invalid`, `example.*`) are DEMO and never an `<a>`. Real links need http/https, an allowed host (`MBOS_LISTING_HOSTS` overrides the list), no credentials, no quotes/whitespace, no redirect parameter; rendered with `rel="noopener noreferrer nofollow"`. Anything else: "No verified live link".
  2. **Photos:** cover thumbnail, count, provenance, enlarge; expired/missing/failed images fall back to a CSS placeholder (CSP forbids script handlers); mockups are in a separate labelled box and never the cover.
  3. **Seller's ad:** verbatim, escaped, line breaks kept (`pre-wrap`), "Show full ad" when long.
  4. **Glance card:** photo, title, price, distance, condition, SOLD vs ASKING comps, net, profit/hour, days to cash, max bid, BUY/WATCH/PASS, one Next action; receipts, reasons and raw JSON collapsed under "View proof".
  5. **Chrome/filters:** active tab (`aria-current`), page `<h1>`, Find Deals Now, all requested filters, session presets, editable tow vehicle/limits (CSRF+PIN, never hard-coded), filtered-out deals listed with reasons (nothing deleted; UNKNOWN fields never exclude).
  6. **My notes:** "Add note" form -> `/notes/add` (owner channel, CSRF+PIN, server-set author, same validation as the card path). On the reference backend the page names the true blocker (needs the lane D store).
  7. **Milestones:** usable now / blocked / future; no dates. Blocked items cite the queue: B-23 adapters are fixture-only, live fetch waits on packet Q3; live messaging is disabled (MICHAEL_DECISIONS #4).
- **Decisions / limits (INFER):** "Profit at least" is an optional user filter with no default floor, so ADR-0012 (no universal profit floor) holds; the field is named `profit_at_least` because the pinned test forbids `min_profit`. Presets are in memory only (lost on restart). "Find Deals Now" re-runs the engine on stored deals; no live source exists, and the page says so. Allowed listing hosts are a proposed default list (owner may edit via env).
- **Tests:** `tests/test_deal_f45.py` (10: link rules, DEMO vs live, HTML injection, missing/expired photo and mockups, glance + proof, filters, tow, presets, chrome/milestones, notes blocker), `tests/lane_d/test_notes_add_f45.py` (notes add over HTTP on lane D). Results in AGENT_STATUS.
